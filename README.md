# Employee Turnover Data Cleaning

A personal/academic project: a Python/pandas script that profiles and cleans the Employee Turnover Dataset — detecting and fixing duplicate records, missing values, inconsistent category labels, formatting errors, and statistical outliers — to prepare it for downstream analysis and modeling.

## What it does

Running `clean_employee_turnover.py` against `Employee_Turnover_Dataset.csv` performs the following, printing a report to the console at each stage:

1. **Load & overview** — reads the raw CSV and reports row/column counts.
2. **Data quality inspection**
   - Counts fully duplicated rows.
   - Counts missing values per column.
   - Lists inconsistent category spellings in `PaycheckMethod` and `JobRoleArea` (e.g. `Direct Deposit` vs `Direct_Deposit` vs `DirectDeposit`).
   - Flags the `HourlyRate` formatting issue (stored as a string like `"$24.37"` with a stray leading/trailing space, and a column name with a trailing space).
   - Detects outliers in `AnnualSalary` and `DrivingCommuterDistance` using the IQR (interquartile range) method, and flags impossible negative values.
3. **Cleaning**
   - Renames the `HourlyRate ` column and converts it from a currency string to a float.
   - Drops duplicate rows.
   - Standardizes inconsistent category labels in `PaycheckMethod` and `JobRoleArea` to a single canonical spelling each.
   - Imputes missing numeric values (`NumCompaniesPreviouslyWorked`, `AnnualProfessionalDevHrs`) with the column median, and missing categorical values (`TextMessageOptIn`) with the column mode.
   - Caps (Winsorizes) outliers in `AnnualSalary` and `DrivingCommuterDistance` to the IQR fences instead of dropping rows, with the lower fence floored at 0.
4. **Post-cleaning summary** — reports final row/column counts and confirms no missing values remain.
5. **Export** — writes the cleaned dataset to `Employee_Turnover_Cleaned.csv`.

## Dataset

`Employee_Turnover_Dataset.csv` is a **synthetic sample dataset** — 308 fabricated records generated for this project, not real employee data. It has 16 columns, including demographic fields (`Age`, `Gender`, `MaritalStatus`), employment fields (`Tenure`, `JobRoleArea`, `CompensationType`, `AnnualSalary`, `HourlyRate`, `HoursWeekly`), and the `Turnover` outcome label (`Yes`/`No`). The generator deliberately seeds the same data-quality issues the cleaning script is built to catch: duplicate rows, missing values, inconsistent category spellings, a currency-formatted rate column, and negative/extreme outliers.

## Requirements

- Python 3.x
- pandas
- numpy

```bash
pip install pandas numpy
```

## Usage

Run from the project root so the script can find the CSV by relative path:

```bash
python clean_employee_turnover.py
```

This prints the full profiling and cleaning report to the console and writes `Employee_Turnover_Cleaned.csv` alongside the script.
